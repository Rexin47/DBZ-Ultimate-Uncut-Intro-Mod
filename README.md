# DBZ Ultimate Uncut Intro (SD and HD Next-Gen Compatible)
Replaces the old opening cinematic of the game with the iconic Dragon Ball Z: Ultimate Uncut Edition Opening, now with Seed of Might's epic quality.

Bring back the peak era of Toonami!

Features:

🎬 HD Video: Scaled and cleaned to preserve pristine visual clarity.

🔊 HQ Audio: 16-bit PCM stereo depth to ensure the guitar tracks sound well.

🔥 SD-HD Compatibility: Built to run on both the original Legacy SD (Standard Edition) and the next-gen HD Remaster update.

____________________________________________________________________________________________________

Download: In the "Releases" tab on the right, click on the main zip file.

Installation:

For Legacy SD Version:

Download and extract the pak file from the zip file:

z_UltimateUncutIntro_P.pak

Navigate to your game directory's "Paks" folder:

.../DRAGON BALL Z KAKAROT/AT/Content/Paks/

Create a folder named (if you haven't already):

~mods

Drag and drop the file directly into the folder (it should look like this):

.../DRAGON BALL Z KAKAROT/AT/Content/Paks/~mods/z_UltimateUncutIntro_P.pak


For Next-Gen HD Remaster Version:

Download and extract the pak file from the zip file:

z_UltimateUncutIntro_P.pak

Navigate to your game directory's "Paks" folder :

.../DRAGON BALL Z KAKAROT/dlc/Remaster/AT/Content/Paks/

Create a folder named (if you haven't already):

~mods

Drag and drop the file directly into the folder (it should look like this):

.../DRAGON BALL Z KAKAROT/dlc/Remaster/AT/Content/Paks/~mods/z_UltimateUncutIntro_P.pak


And you're done!
